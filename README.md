# Easy DevOps Documentation Site

The documentation website for Easy DevOps, built with Next.js 15 (App Router).

## Tech Stack

- **Next.js 15** — App Router, React Server Components
- **React 19** — typed with TypeScript 6
- **Tailwind CSS v4** — styling, through `@tailwindcss/postcss` (there is no Tailwind v3 config file driving the build; the theme lives in `app/globals.css`)
- **next-themes** — dark/light mode
- **react-syntax-highlighter** — code block syntax highlighting
- **framer-motion** — animations
- **lucide-react** — icons

## Getting Started

```bash
# Install dependencies
npm install

# Run the dev server on http://localhost:3000
npm run dev

# Lint (next lint; the repo has no ESLint config, so it prompts on first run)
npm run lint

# Production build (writes .next/)
npm run build

# Serve the production build
npm run start
```

`next.config.ts` does **not** set `output: "export"`, so `npm run build` produces a
normal Next.js server build in `.next/` — the `out/` folder is not generated by
this project's build. `npm run start` serves the result.

## Project Structure

```

  layout.tsx              root layout (fonts, theme provider, global styles)
  page.tsx                landing page
  LandingPage.tsx         landing page sections
  globals.css             Tailwind 4 + design tokens
  docs/
    layout.tsx            docs layout (sidebar, search, TOC, theme toggle)
    page.tsx              redirects to /docs/overview

    features/             features
    installation/         installation (OS tabs)
    quickstart/           quick start
    cli/                  interactive CLI and flags
    commands/             command reference
    ssl/                  SSL manager
    deployments/          git deployments
    service/              background service and pinned runtime
    hub/                  Easy DevOps Hub
    maintenance/          updates, cleanup, backup, setup codes
    api/                  dashboard API introduction (links to the contract)
    configuration/        settings reference
    platform/             platform support
    faq/                  FAQ and troubleshooting

components/               CodeBlock, CmdTable, InstallTabs, DocsSidebar,
                          DocsSearch, OnThisPage, and the rest of the UI
lib/                      docs index, site constants, live version lookup
```

## Editing content

The facts on these pages come from the code in the easy-devops repository:
`src/`, `API-CONTRACT.md` and the `CHANGELOG.md` `[Unreleased]` section. The
dashboard API page deliberately links to
[API-CONTRACT.md](https://github.com/omar00050/Easy-DevOps/blob/main/API-CONTRACT.md)
rather than duplicating the endpoint list.

## Deploy

Any host that runs Next.js can serve it. On Vercel, import the repository and let
it run `npm run build`.
